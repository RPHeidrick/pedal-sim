    Netlist conventions
    • Input node in, output node out, supply node vcc, ground 0 (or gnd).
    • A V source on in is replaced by the audio input; one is added if missing. A 9 V supply is added if vcc has no source.
    • Pots: XVOL lug1 wiper lug3 pot R=500k taper=log rot=0.5 (taper lin | log | rlog; also pot_log etc.), or resistor pairs RVOL_A lug1 w + RVOL_B w lug3. Clockwise moves the wiper toward lug 3.
    • Switches: XS1 c a b spdt state=0, dpdt (c1 a1 b1 c2 a2 b2), spst (a b). State 0 connects c–a.
    • Op amps: XU1 in+ in- v+ v- out TL072 (or JRC4558, NE5532, LM358, opamp …) uses the built-in macromodel unless a working .subckt is supplied.
    • Annotations in comments: *@pot XVOL taper=log label="Volume", *@switch XS1 label="Mode", *@pedal name="My Fuzz".
    • Upload .include/.lib files together with the netlist (multi-select).
